# 実装計画

仕様は [design.md](design.md) にある。
この資料は、実装を Issue 単位に分けた順序と進捗を記録する。

各 Issue は 1 つの PR で対応し、PR は前の Issue のブランチに積む(スタック式)。
マージは先頭の PR から順に行う。

| 順 | Issue | 内容 | 状態 |
| --- | --- | --- | --- |
| 1 | 基盤と常駐 | ソリューション構成、設定の保存と読み込み、トレイ常駐、多重起動の防止、自動起動、ホットキー登録、設定画面、`build-debug.bat` と `build-release.bat` | 未着手 |
| 2 | スクリーンショット | 全体、範囲、ウィンドウの静止画。範囲選択の重ね合わせ、JPEG と PNG、カーソル、クリップボード、保存の通知 | 未着手 |
| 3 | 動画の映像 | Desktop Duplication と Windows.Graphics.Capture の取得、Sink Writer による H.264 と MP4、録画の操作バー、一時停止 | 未着手 |
| 4 | 動画の音声 | ループバックとマイクの収録、混合、AAC の格納、ffmpeg による MP3 | 未着手 |
| 5 | 更新 | update.json の確認、通知、自己更新 | 未着手 |
| 6 | 配布 | `build-package.bat`、配布サイトの生成とアップロード、マニュアル、ライセンス、ffmpeg の取得 | 未着手 |
