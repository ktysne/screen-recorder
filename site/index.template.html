キーひとつで、
画面を撮る、録る。

ScreenRecorder は、タスクトレイに常駐する Windows 用の画面キャプチャアプリです。画面の静止画と動画を、ショートカットキーかトレイのメニューから撮れます。

ダウンロード v{{VERSION}} マニュアルを読む

Windows 10 バージョン 2004 以降 (x64)。zip を展開するだけで使えます。

主な機能

  • 範囲、ウィンドウ、画面全体を撮る
  • 画面を動画で録る
  • PC の音とマイクを録る
  • ショートカットキーで操作
  • 保存とクリップボードへのコピー
  • 新しい版への更新

撮りたいときに、すぐ撮れる

ウィンドウを開かずに、トレイに置いたまま使います。撮り方を選んで対象を指すだけで、保存まで進みます。

範囲、ウィンドウ、画面全体を撮る

ドラッグで囲んだ範囲、クリックしたウィンドウ、カーソルのあるディスプレイ全体の 3 通りで静止画を撮れます。

画面を動画で録る

撮り方は静止画と同じです。3 秒のカウントダウンのあとに録画が始まり、操作バーから一時停止と停止ができます。

PC の音とマイクを録る

スピーカーから出る音を録音します。マイクもオンにすると、2 つを混ぜて 1 本の音声にします。

ショートカットキーで操作

PrtSc で範囲の静止画、Shift + PrtSc で範囲の録画を始めます。キーは設定で変えられます。

保存とクリップボードへのコピー

静止画は保存と同時にクリップボードへもコピーします。保存を知らせる通知を押すと、保存先でファイルが選ばれた状態で開きます。

新しい版への更新

新しい版が出ると通知でお知らせします。「今すぐ更新」を選ぶと、ダウンロードから入れ替えと起動し直しまで進みます。

ひととおりの流れ

インストールは要りません。

  1. 展開して起動する

    zip を好きなフォルダーに展開し、ScreenRecorder.exe を起動します。

  2. トレイに常駐する

    画面右下の通知領域にアイコンが出ます。サインイン時にも自動で起動します。

  3. 撮る、録る

    ショートカットキーか、トレイアイコンの右クリックメニューから撮り方を選びます。

  4. 保存先で確かめる

    静止画は「ピクチャ」、動画は「ビデオ」の中の ScreenRecorder フォルダーに保存されます。

ダウンロード

インストーラはありません。zip を書き込みできる場所へ展開し、中の ScreenRecorder.exe を起動してください。

導入と更新

  • zip の中のファイルは、すべて同じフォルダーに置いたまま使ってください。
  • 初回の起動で SmartScreen の警告が出たときは、「詳細情報」を押してから「実行」を押します。
  • 「Program Files」のような管理者の権限が要るフォルダーに置いた場合は、自動では更新できません。新しい zip を展開し直してください。
